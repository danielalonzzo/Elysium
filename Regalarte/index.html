Conexión a Servidor Requerida

El prototipo inmersivo de Regalarte está construido con tecnología Server-Side Rendering (Vinext/React). ElysiumDR (donde está alojado Elysium) solo soporta archivos estáticos y no puede ejecutar código de servidor.

Para que este enlace funcione de forma pública en elysiumdr.eu/regalarte, necesitamos desplegar el código en un proveedor en la nube como Cloudflare Pages.
