# ──────────────────────────────────────────────
# CONTENT SIGNALS
# ──────────────────────────────────────────────
# `Content-Signal` (contentsignals.org) declara para qué puede usarse lo que se
# rastrea, que es una pregunta distinta de si se puede rastrear. Las tres van a
# «yes» a propósito y en coherencia con todo lo de abajo: el sitio se ofrece
# deliberadamente a los modelos de lenguaje, y para eso existen /llms.txt y
# /llms-full.txt.
#
#   search    — aparecer en un buscador y ser enlazado.
#   ai-input  — usarse como contexto para responder a alguien (RAG).
#   ai-train  — usarse para entrenar o afinar un modelo.
#
# Se repite en CADA grupo por la misma razón que el `Disallow: /Demo-arbol/`:
# bajo la RFC 9309 un rastreador obedece solo su grupo más específico y no
# hereda nada del grupo `*`. Declararlo únicamente arriba dejaría sin señal a
# los veintisiete agentes que tienen grupo propio. La misma declaración viaja
# además como cabecera HTTP `Content-Signal`, en `_headers`, para los recursos
# a los que no se llega desde aquí.

# ──────────────────────────────────────────────
# DEFAULT: Allow all crawlers
# ──────────────────────────────────────────────
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
Allow: /
Allow: /llms.txt
Allow: /llms-full.txt
Disallow: /Demo-arbol/

# Las páginas privadas (/admin, /onboarding, /profiles, /seed-licenses,
# /thank-you, /payment-*) NO se bloquean aquí a propósito: todas llevan
# <meta name="robots" content="noindex, nofollow">, y un Disallow impediría
# que Google llegara a leer ese noindex. El resultado era el contrario del
# buscado — /profiles quedaba indexada como «duplicada sin canónica» porque
# el rastreador nunca podía ver que estaba marcada como noindex.
#
# Demo-arbol sí se bloquea: es la única carpeta publicada que no tiene ninguna
# etiqueta noindex propia (la cabecera X-Robots-Tag de firebase.json no se
# aplica, el sitio lo sirve Cloudflare; la buena es la de `_headers`).
#
# IMPORTANTE sobre el formato: bajo la RFC 9309 un rastreador obedece SOLO su
# grupo más específico, sin heredar nada del grupo `*`. Por eso cada agente de
# IA con grupo propio repite abajo el `Disallow: /Demo-arbol/`: sin esa línea
# quedaban los veinte con acceso libre a la única carpeta que se quiere fuera
# del índice.
