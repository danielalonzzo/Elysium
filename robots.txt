# Las páginas privadas (/admin, /onboarding, /profiles, /seed-licenses,
# /thank-you, /payment-*) NO se bloquean aquí a propósito: todas llevan
# <meta name="robots" content="noindex, nofollow">, y un Disallow impediría
# que Google llegara a leer ese noindex. El resultado era el contrario del
# buscado — /profiles quedaba indexada como «duplicada sin canónica» porque
# el rastreador nunca podía ver que estaba marcada como noindex.
#
# Demo-arbol sí se bloquea: es la única carpeta publicada que no tiene ninguna
# etiqueta noindex propia (la cabecera X-Robots-Tag de firebase.json no se
# aplica, el sitio lo sirve Cloudflare; la buena es la de `_headers`).
#
# IMPORTANTE sobre el formato: bajo la RFC 9309 un rastreador obedece SOLO su
# grupo más específico, sin heredar nada del grupo `*`. Por eso cada agente de
# IA con grupo propio repite abajo el `Disallow: /Demo-arbol/`: sin esa línea
# quedaban los veinte con acceso libre a la única carpeta que se quiere fuera
# del índice.
