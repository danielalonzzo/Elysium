How it works

  1. Drop the PDF above.
  2. Click the pages you want to keep; Shift-click selects a whole range.
  3. Press Download selected pages. Repeat with another selection to split the document into several files.

Split a PDF in parts

To split a document, select the first part and download it, then select the next one. Each download is an independent PDF with its own name.

Keep the order you choose

The extracted file keeps the order shown in the editor, so you can also reorder or rotate pages before extracting them.

Frequently asked questions

Does extracting remove pages from my original?

No. The original file is not modified; you get a new PDF with the selected pages.

Can I extract pages from several PDFs at once?

Yes. Add the files, select pages from any of them and download the selection as one PDF.

Is there a page limit?

No fixed limit; files can be up to 200 MB each.

Are my PDF files uploaded?

Not to edit them: merging, reordering, rotating, deleting and extracting pages happen inside your browser and the file never leaves your device. Only “Convert to Word” sends the edited PDF to the Elysium server, which deletes it as soon as the Word file exists.

Is it free?

Yes, with no ads, watermarks; a verified account and an approved free license are required. Word conversion allows 10 documents per hour per visitor so the service stays available.
