Ordenar as páginas de um PDF

Ponha as páginas de um PDF na ordem certa arrastando-as. Mova uma página ou uma seleção inteira e transfira o documento reorganizado.

Largue aqui os seus PDF

Ordene, rode e elimine páginas, junte vários PDF ou converta-os para Word.

As páginas são editadas neste navegador: os ficheiros não saem do seu computador.

    Arraste as páginas para as ordenar (no telemóvel, mantenha uma premida e arraste). Clique para selecionar; com Shift seleciona um intervalo.

      O Word (.docx) abre no Word, no Pages e no Google Docs. Para converter, o PDF é enviado para o servidor da Elysium, que o apaga assim que o Word está pronto.

      Largue os PDF para os adicionar

      Como funciona

      1. Largue o PDF acima. Cada página aparece com o seu número.
      2. Arraste uma página para o novo lugar. Se houver várias selecionadas, movem-se juntas. No telemóvel, mantenha a página premida um momento antes de arrastar.
      3. Prima Transferir PDF para guardar a nova ordem.

      Arrastar, teclado ou botões

      Use o que for mais confortável: arrastar com o rato, os botões ‹ e › de cada página, ou selecionar uma página e premir Alt + setas para a mover.

      Entre vários ficheiros

      Adicione mais PDF ao editor e poderá misturar as suas páginas numa única ordem nova antes de guardar.

      Perguntas frequentes

      Posso mover várias páginas de uma vez?

      Sim. Selecione-as primeiro; ao arrastar uma delas move-se a seleção inteira.

      Funciona no telemóvel ou no tablet?

      Sim. Mantenha uma página premida até levantar e arraste-a.

      Posso anular um movimento?

      Sim. Anular volta atrás passo a passo.

      Os meus PDF são enviados para algum servidor?

      Para os editar, não: juntar, ordenar, rodar, eliminar e extrair páginas acontece dentro do seu navegador e o ficheiro não sai do seu dispositivo. Só «Converter para Word» envia o PDF editado para o servidor da Elysium, que o apaga assim que o Word existe.

      É grátis?

      Sim, sem anúncios, marcas de água nem registo. A conversão para Word admite 10 documentos por hora e visitante para o serviço continuar disponível.
