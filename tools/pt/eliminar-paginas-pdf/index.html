Eliminar páginas de um PDF

Retire páginas em branco, capas, duplicados ou o que não quer partilhar, e guarde uma cópia limpa do PDF.

Largue aqui os seus PDF

Ordene, rode e elimine páginas, junte vários PDF ou converta-os para Word.

As páginas são editadas neste navegador: os ficheiros não saem do seu computador.

    Arraste as páginas para as ordenar (no telemóvel, mantenha uma premida e arraste). Clique para selecionar; com Shift seleciona um intervalo.

      O Word (.docx) abre no Word, no Pages e no Google Docs. Para converter, o PDF é enviado para o servidor da Elysium, que o apaga assim que o Word está pronto.

      Largue os PDF para os adicionar

      Como funciona

      1. Largue o PDF acima e reveja as miniaturas.
      2. Clique nas páginas a retirar e prima Eliminar, ou use o × de uma página. Anular recupera-as.
      3. Prima Transferir PDF para guardar o documento sem essas páginas.

      Uma cópia limpa para partilhar

      Eliminar páginas é a forma mais rápida de enviar só a parte importante de um documento: a página assinada de um contrato, um capítulo de um relatório, as faturas de um só mês.

      Nada sai do seu dispositivo

      As páginas são retiradas pelo seu navegador. O PDF não é enviado, por isso pode usá-lo com documentos que contêm dados pessoais.

      Perguntas frequentes

      O meu PDF original é alterado?

      Não. Transfere um PDF novo; o ficheiro original fica como estava.

      Posso eliminar muitas páginas de uma vez?

      Sim. Use Selecionar tudo ou clique com Shift para selecionar um intervalo, e prima Eliminar.

      Posso recuperar uma página eliminada?

      Sim, com Anular, desde que não tenha recomeçado o editor.

      Os meus PDF são enviados para algum servidor?

      Para os editar, não: juntar, ordenar, rodar, eliminar e extrair páginas acontece dentro do seu navegador e o ficheiro não sai do seu dispositivo. Só «Converter para Word» envia o PDF editado para o servidor da Elysium, que o apaga assim que o Word existe.

      É grátis?

      Sim, sem anúncios, marcas de água nem registo. A conversão para Word admite 10 documentos por hora e visitante para o serviço continuar disponível.
