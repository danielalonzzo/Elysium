Como funciona

  1. Largue um ou vários PDF acima, ou escolha-os no seu dispositivo.
  2. Arraste as páginas para a ordem que quiser; selecione páginas para as rodar, eliminar ou extrair. Anular está sempre a um clique.
  3. Transfira o PDF novo, só as páginas selecionadas, ou converta o resultado para Word.

O seu PDF não sai do seu dispositivo

Juntar, ordenar, rodar, eliminar e extrair páginas é feito pelo seu navegador com bibliotecas de código aberto (pdf.js e pdf-lib). Para estas tarefas o documento nunca é enviado, por isso também servem para ficheiros confidenciais.

Word, Pages e Google Docs

«Converter para Word» reconstrói os parágrafos, as tabelas e as imagens do PDF num .docx que abre no Microsoft Word, no Apple Pages, no Google Docs e no LibreOffice. Os PDF digitalizados ficam como páginas com imagens, porque não há texto para reconhecer.

Perguntas frequentes

Que tamanho pode ter o meu PDF?

Até 200 MB por ficheiro para editar. A conversão para Word aceita até 30 MB e 500 páginas.

Posso editar PDF com palavra-passe?

Não. Retire primeiro a palavra-passe. Os PDF com restrições de permissões podem ser convertidos para Word tal como estão, mas não reescritos.

Acrescenta marca de água?

Não. O PDF que transfere contém apenas as suas páginas.

Os meus PDF são enviados para algum servidor?

Para os editar, não: juntar, ordenar, rodar, eliminar e extrair páginas acontece dentro do seu navegador e o ficheiro não sai do seu dispositivo. Só «Converter para Word» envia o PDF editado para o servidor da Elysium, que o apaga assim que o Word existe.

É grátis?

Sim, sem anúncios, marcas de água; são necessárias uma conta confirmada e uma licença gratuita aprovada. A conversão para Word admite 10 documentos por hora e visitante para o serviço continuar disponível.
