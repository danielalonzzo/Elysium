Converter PDF para Word

Transforme um PDF num documento Word editável. Os parágrafos, as tabelas e as imagens são reconstruídos num .docx que abre no Word, no Pages, no Google Docs e no LibreOffice.

Largue aqui os seus PDF

Ordene, rode e elimine páginas, junte vários PDF ou converta-os para Word.

As páginas são editadas neste navegador: os ficheiros não saem do seu computador.

      Como funciona

      1. Largue o seu PDF acima. Se só precisar de algumas páginas, elimine ou ordene primeiro as restantes.
      2. Prima Converter para Word e acompanhe o progresso página a página.
      3. O .docx é transferido automaticamente quando estiver pronto.

      Como funciona a conversão

      O PDF editado é enviado para o servidor da Elysium, que analisa a paginação de cada página e escreve o documento Word equivalente. O PDF é apagado assim que o .docx existe, e o .docx é apagado ao fim de 15 minutos.

      O que esperar

      O texto, as tabelas, as imagens e a formatação básica são mantidos para os poder editar. As paginações complexas — várias colunas, texto sobre imagens — podem precisar de ajustes. Os PDF digitalizados não têm texto, por isso as páginas chegam como imagens.

      Perguntas frequentes

      Posso abrir o resultado no Pages?

      Sim. O Pages abre ficheiros .docx diretamente, tal como o Word, o Google Docs e o LibreOffice.

      Reconhece o texto de PDF digitalizados (OCR)?

      Ainda não. Se o PDF for uma digitalização, a página é inserida como imagem e a ferramenta avisa.

      Quais são os limites?

      Até 30 MB e 500 páginas por PDF, e 10 conversões por hora.

      Os meus PDF são enviados para algum servidor?

      Para os editar, não: juntar, ordenar, rodar, eliminar e extrair páginas acontece dentro do seu navegador e o ficheiro não sai do seu dispositivo. Só «Converter para Word» envia o PDF editado para o servidor da Elysium, que o apaga assim que o Word existe.

      É grátis?

      Sim, sem anúncios, marcas de água nem registo. A conversão para Word admite 10 documentos por hora e visitante para o serviço continuar disponível.
